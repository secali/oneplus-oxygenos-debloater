> **Targeted ADB debloat automation script customized for OnePlus OxygenOS 14 (ColorOS base) to optimize standby battery drain and RAM allocation.**

---

## 🎯 Overview

With the consolidation of OxygenOS and ColorOS, modern OnePlus devices (such as the OnePlus Nord 3 and OnePlus 11/12 series) contain background HeyTap services, analytics trackers, and preinstalled partner apps.

This script executes vetted package uninstalls for the current user profile, delivering a cleaner, near-stock Android experience with zero bloat.

### 🌟 Key Features
- **Curated Package Whitelist**: Specifically vetted for OxygenOS 14 to avoid breaking camera, fingerprint reader, or OnePlus shelf.
- **One-Click Execution**: Interactive batch script with detailed package descriptions.

---

## 🚀 Execution

```cmd
git clone https://github.com/secali/oneplus-oxygenos-debloater.git
cd oneplus-oxygenos-debloater
debloat_OOS14_for_Nord3.bat
```
